# data-annotation-portfolio
Image Annotation and Polygon Segmentation

Project Overview

This project demonstrates my practical experience in image annotation and polygon-based segmentation using Roboflow.

Work Performed

- Annotated images using polygon tools.
- Assigned appropriate class labels.
- Created polygon segmentation annotations.
- Exported annotations in YOLO segmentation format.
- Organised images and annotation files.

Tools Used

- Roboflow
- YOLO Segmentation Format

Project Structure

- Original-Images: Original images.
- Annotated-Images: Images with visible polygon annotations.
- Labels: YOLO segmentation TXT files.

Skills Demonstrated

- Image Annotation
- Polygon Segmentation
- Object Labelling
- Class Identification
- Dataset Organisation

Objective

To demonstrate my practical skills in preparing accurate image annotations for computer vision applications.
